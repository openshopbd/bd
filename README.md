# Openshop — অ্যাডমিন-নিয়ন্ত্রিত ই-কমার্স ওয়েবসাইট

একটা সম্পূর্ণ অনলাইন শপ, যেখানে **অ্যাডমিন প্যানেল থেকে সব কিছু নিয়ন্ত্রণ করা যায়** — প্রোডাক্ট, অফার/ছাড়, কুপন, সাইটের রং-লোগো-ব্যানার, আর প্রতিটা অর্ডারের ট্র্যাকিং স্ট্যাটাস। ফ্রন্টএন্ড ভ্যানিলা HTML/CSS/JS দিয়ে বানানো, ব্যাকএন্ড Firebase/Firestore, GitHub Pages-এ হোস্ট করার জন্য উপযুক্ত। PWA হিসেবে হোম স্ক্রিনে অ্যাপের মতো ইনস্টল করা যায় (স্টোরফ্রন্ট ও অ্যাডমিন আলাদাভাবে)।

---

## ফাইল স্ট্রাকচার
- `index.html`, `style.css`, `script.js` — মূল স্টোরফ্রন্ট (কাস্টমার-facing ওয়েবসাইট)
- `admin.html` — অ্যাডমিন ড্যাশবোর্ড (অ্যানালিটিক্স, প্রোডাক্ট, অর্ডার ও ট্র্যাকিং, কুপন ও অফার, সাইট সেটিংস, রিভিউ, গ্রাহক তালিকা)
- `products.js` — Firebase কনফিগার না থাকলে ব্যবহৃত হবে এমন স্ট্যাটিক ফলব্যাক প্রোডাক্ট তালিকা
- `firebase-config.js` — Firebase কানেকশনের তথ্য
- `bd-locations.js` — চেকআউট ফর্মের জেলা/উপজেলা ড্রপডাউনের ডেটা
- `manifest.json`, `admin-manifest.json`, `sw.js` — হোম স্ক্রিনে অ্যাপ হিসেবে ইনস্টল ও অফলাইন সাপোর্টের জন্য
- `firestore.rules` — Firebase Console-এ কপি-পেস্ট করার জন্য (নিচে "Firestore Rules" সেকশন দেখুন)
- `images/` — লোগো, হিরো ব্যাকগ্রাউন্ড, ও প্রোডাক্ট ছবি

## Firestore Rules (আপডেট করুন) — "Missing or insufficient permissions" এররের সমাধান
এই zip-এ থাকা `firestore.rules` ফাইলটা খুলে পুরো কন্টেন্ট কপি করুন, অথবা নিচেরটা কপি করুন। তারপর Firebase Console → Firestore Database → Rules-এ বসিয়ে Publish করুন:
```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /products/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /settings/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /events/{doc}   { allow read: if request.auth != null; allow create: if true; }
    match /leads/{doc}    { allow read: if request.auth != null; allow create: if true; }
    match /orders/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
    match /coupons/{doc} { allow read: if true; allow write: if request.auth != null; }
    match /reviews/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
    match /likes/{doc} {
      allow read: if true;
      allow create: if true;
      allow update, delete: if request.auth != null;
    }
  }
}
```

## কাস্টমার-facing ফিচার (একনজরে)

### হোমপেজ ও ব্রাউজিং
- **হিরো ব্যানার স্লাইডার** — ছাড় থাকা প্রোডাক্ট থেকে অটো-জেনারেট হওয়া স্লাইড
- **⚡ ফ্ল্যাশ সেল সেকশন** — সবচেয়ে বেশি ছাড় থাকা প্রোডাক্টগুলো হরাইজন্টাল স্ক্রলে, সাথে "আজ রাত ১২টায় শেষ" কাউন্টডাউন টাইমার। ছাড় থাকা প্রোডাক্ট না থাকলে সেকশনটা নিজে থেকেই লুকিয়ে যায়।
- **🏷️ কুপন/ভাউচার স্ট্রিপ** — হোমপেজে চালু থাকা কুপনগুলো কার্ড আকারে দেখায়, ট্যাপ করলে কোড কপি হয়ে যায়
- **🕒 সম্প্রতি দেখেছেন সেকশন** — আপনি যেসব প্রোডাক্ট দেখেছেন সেগুলো ব্রাউজারে (localStorage) মনে রাখা হয় ও হোমপেজে দেখানো হয়
- **গোল আইকন ক্যাটাগরি স্ট্রিপ** — মূল ক্যাটাগরিগুলো দারাজ-স্টাইলে গোল আইকন বাটনে, ট্যাপ করলে সাব-ক্যাটাগরি দেখায়
- **সার্চ + ট্রেন্ডিং সাজেশন** — সার্চ বক্সে টাইপ করলে লাইভ প্রোডাক্ট সাজেশন দেখায়; খালি অবস্থায় ট্যাপ করলে জনপ্রিয় সার্চ চিপ দেখায়
- **সাজানো/সর্ট ও ফিল্টার** — দাম (কম→বেশি / বেশি→কম), নাম অনুযায়ী সাজানো; দামের রেঞ্জ ও ন্যূনতম রেটিং দিয়ে ফিল্টার
- **ডার্ক মোড 🌙** — হেডার/প্রোফাইল মেনু থেকে টগল, পছন্দ মনে রাখে

### প্রোডাক্ট কার্ড ও ডিটেইল
- ছাড়ের ব্যাজ, একাধিক ছবি থাকলে ছবি-কাউন্ট ব্যাজ, স্টক আউট/লো-স্টক নোটিশ
- **🚚 ফ্রি ডেলিভারি ব্যাজ** ও **ব্র্যান্ড ট্যাগ** — অ্যাডমিন প্রোডাক্ট ফর্মে সেট করলে কার্ড ও প্রোডাক্ট মডাল দুই জায়গাতেই দেখা যায়; সেট না করলে কোনো খালি জায়গা দেখায় না
- হার্ট আইকনে ❤️ **উইশলিস্ট**-এ যোগ, রেটিং ব্যাজ, "✍️ রিভিউ দিন" ট্যাগ (সরাসরি রিভিউ ফর্মে নিয়ে যায়)
- প্রোডাক্ট মডালে: গ্যালারি, ভ্যারিয়েন্ট/সাইজ বাছাই, রিলেটেড প্রোডাক্ট ("এগুলোও দেখতে পারেন"), কাস্টমার রিভিউ ও রেটিং, শেয়ার বাটন, লাইক বাটন, "কার্টে যোগ" এনিমেশন (ছবি উড়ে গিয়ে কার্ট আইকনে বাম্প ইফেক্ট)

### কার্ট ও চেকআউট
- কার্ট ড্রয়ারে প্রোডাক্ট লিস্ট আলাদাভাবে স্ক্রল হয়, হেডার ও চেকআউট ফর্ম সবসময় ফিক্সড থাকে
- প্রোডাক্ট-নির্দিষ্ট কুপন প্রতিটা কার্ট-আইটেমের নিচে ছোট ট্যাগ হিসেবে প্রয়োগ/বাদ দেওয়া যায়; সাধারণ (নন-প্রোডাক্ট) কুপন ফুটারে
- সাবটোটাল, ডেলিভারি চার্জ, ছাড়, ও লাইভ-আপডেট হওয়া **সর্বমোট**
- **লোকেশন পারমিশন বাধ্যতামূলক** — চেকআউটের আগে ব্রাউজার লোকেশন Allow করা না থাকলে অর্ডার আটকে যায় ও আবার পারমিশন চাওয়া হয় (ভুয়া/ফেক ঠিকানার অর্ডার কমাতে)
- চেকআউট করলে সাথে সাথে (কোনো await ছাড়াই) WhatsApp চ্যাট খোলে, ছবিসহ অর্ডার মেসেজ যায় (মোবাইলে নেটিভ শেয়ার শিট, ডেস্কটপে ছবির লিংকসহ মেসেজ)
- অর্ডার সম্পন্ন হলে কপি-করা-যায় এমন অর্ডার আইডি পপআপে দেখায়

### প্রোফাইল / অর্ডার ট্র্যাকিং
- **প্রোফাইল ড্রয়ারে দারাজ-স্টাইল কুইক-মেনু আইকন গ্রিড** — উইশলিস্ট, কুপন, ডার্ক মোড, কাস্টমার কেয়ার, শেয়ার, অ্যাপ ইনস্টল, ফেসবুক পেজ, WhatsApp — সব এক ট্যাপে
- অর্ডার আইডি দিয়ে অর্ডারের বর্তমান অবস্থা দেখা যায় (গোপনীয়তার জন্য ফোন নম্বর দিয়ে সার্চ নেই) (অপেক্ষমাণ / নিশ্চিত হয়েছে / প্রস্তুত হচ্ছে / পাঠানো হয়েছে / ডেলিভারি সম্পন্ন / বাতিল)

### অন্যান্য
- উইশলিস্ট ড্রয়ার (হেডার আইকন থেকে)
- হোয়াটসঅ্যাপ + মেসেঞ্জার ফ্লোটিং বাটন
- লিংক শেয়ারে Open Graph প্রিভিউ কার্ড (WhatsApp/Facebook)
- অফলাইন সাপোর্ট (ছবি cache-first, বাকি সব network-first যাতে আপডেট সাথে সাথে দেখা যায়)

## অ্যাডমিন-facing ফিচার (একনজরে)

### প্রোডাক্ট ম্যানেজমেন্ট
- নাম, মেইন/সাব-ক্যাটাগরি, দাম, পুরাতন মূল্য (ছাড় দেখাতে), স্টক, ক্রয়মূল্য (কাস্টমারকে দেখানো হয় না — শুধু স্মার্ট কুপন সাজেশনে ব্যবহৃত), ভ্যারিয়েন্ট/সাইজ, বিবরণ
- **ব্র্যান্ড** ফিল্ড ও **ফ্রি ডেলিভারি** চেকবক্স — সেট করলেই স্টোরফ্রন্টে সংশ্লিষ্ট ব্যাজ দেখায়
- একসাথে একাধিক ছবি আপলোড (গ্যালারি থেকে বাছাই → অটো আপলোড → থাম্বনেইল গ্রিড), প্রতিটা ছবিতে টেক্সট/ইমোজি/ফিল্টার বসানোর এডিটর, ড্র্যাগ-টু-রিসাইজ হ্যান্ডেল ও ব্র্যান্ড ব্যাজ লেয়ার
- বাল্ক সিলেক্ট মোড — একাধিক প্রোডাক্টে একসাথে পরিবর্তন প্রয়োগ

### অর্ডার ও ট্র্যাকিং
- প্রতিটা অর্ডারের স্ট্যাটাস বদলানো যায়, CSV এক্সপোর্ট (বর্তমান ফিল্টার অনুযায়ী)
- লোকেশন পারমিশন দেওয়া থাকলে "🗺️ ম্যাপে লোকেশন দেখুন" লিংক

### কুপন ও অফার
- **একাধিক কুপন** একসাথে চালু রাখা যায়, প্রতিটাতে আলাদা ছাড়ের ধরন (% বা ৳), সর্বনিম্ন অর্ডার, সর্বোচ্চ ব্যবহার সীমা, মেয়াদ শেষের তারিখ, ও চালু/বন্ধ টগল
- **📢 ফেসবুক ক্যাপশন জেনারেটর** ও **🏷️ কুপন জেনারেটর** — সম্পূর্ণ আলাদা দুটো টুল (একসাথে জড়ানো ছিল না, ইচ্ছাকৃতভাবে আলাদা করা হয়েছে): একটা শুধু পোস্টের লেখা বানায়, আরেকটা শুধু নতুন কুপন কোড বানিয়ে সেভ করে

### রিভিউ
- প্রোডাক্ট অনুযায়ী ফিল্টার করে অনুপযুক্ত/ভুয়া রিভিউ মুছে ফেলা যায়

### সাইট সেটিংস
- থিমের প্রধান/এক্সেন্ট রং, উপরের অফার ব্যানার লেখা, কভার ফটো/লোগো/হিরো টেক্সট, যোগাযোগের তথ্য, কুপন ম্যানেজমেন্ট
- অ্যানালিটিক্সে লো-স্টক অ্যালার্ট ও স্টকে বেশি পড়ে থাকা প্রোডাক্টের তালিকা

## কুপন সিস্টেম কীভাবে কাজ করে
অ্যাডমিন → "কুপন ও অফার" ট্যাব থেকে একসাথে একাধিক কুপন যোগ করা যায়। কাস্টমার চেকআউটের সময় কোড লিখে "প্রয়োগ করুন" চাপলে শর্তগুলো Firestore থেকে যাচাই হয়, আর চেকআউটের ঠিক আগমুহূর্তেও আরেকবার যাচাই হয় (যাতে অ্যাডমিন কুপন বন্ধ করে দিলে পুরনো ছাড় প্রয়োগ না হয়)।

**⚠️ কুপন কোড সাধারণত সাইটে প্রকাশ্যে দেখানো হয় না** — প্রোডাক্ট কার্ড/মডালের কুপন-চিপে ও হ্যামবার্গার মেনুর কুপন তালিকায় শুধু কুপনের নাম/লেবেল ও ছাড়ের পরিমাণ দেখা যায়, "ব্যবহার করুন" চাপলেই কোড না দেখিয়ে প্রয়োগ হয়ে যায়। (ব্যতিক্রম: হোমপেজের ভাউচার স্ট্রিপে কোড দেখিয়ে "কপি করুন" অপশন আছে, যেহেতু এটা অ্যাডমিন ইচ্ছাকৃতভাবে পাবলিক প্রচারের জন্য বসানো কুপনের জন্য বানানো হয়েছে।) কাস্টমারকে গোপন কোড জানাতে ফেসবুক পোস্টের কমেন্ট/ইনবক্স ব্যবহার করুন — এডমিন প্যানেলের ক্যাপশন জেনারেটর এই কাজে সাহায্য করে।

## লোকেশন — অর্ডার করার জন্য বাধ্যতামূলক
সাইটে ঢোকার সাথে সাথে ব্রাউজারের Geolocation API দিয়ে ভিজিটরের অবস্থান নেওয়ার চেষ্টা হয় (ব্রাউজারের নিজস্ব "Allow করবেন?" পপআপ, কোনো সাইট এড়াতে পারে না)। চেকআউট বাটনে চাপার সময় পারমিশন দেওয়া না থাকলে অর্ডার আটকে যাবে ও আবার পারমিশন চাওয়া হবে। Allow করা থাকলে lat/lng অর্ডারের সাথে সেভ হয় ও এডমিন প্যানেলে ম্যাপ লিংক আকারে দেখা যায়।

## অর্ডার গোপনীয়তা ও Firestore Rules
- `orders` কালেকশন **লিস্ট করা যায় না** (শুধু অ্যাডমিন পারে); আইডি জানা থাকলে শুধু সেই একটা অর্ডার `get` করা যায়
- কুপনের `maxUses` চেক এখন `couponUsage/{CODE}` কাউন্টার থেকে হয়; অ্যাডমিন প্যানেলের কুপন ট্যাব খুললে কাউন্টার আসল অর্ডার-সংখ্যার সাথে নিজে থেকে মিলে যায়
- `firestore.rules` পরিবর্তন করলে Firebase Console → Firestore → Rules এ বসিয়ে **Publish** করতে হবে
- পুরনো অর্ডার (র‍্যান্ডম ডকুমেন্ট ID সহ) কাস্টমার আর আইডি দিয়ে ট্র্যাক করতে পারবেন না; অ্যাডমিন প্যানেলে সব ঠিকঠাক দেখা যাবে

## অর্ডার ট্র্যাকিং কীভাবে কাজ করে
1. কাস্টমার কার্ট থেকে চেকআউট করলে নাম, ফোন (বাধ্যতামূলক), ঠিকানা দেন
2. একটা লম্বা র‍্যান্ডম অর্ডার আইডি (যেমন `OSK7M2QX9T`) তৈরি হয় ও Firestore-এর `orders` কালেকশনে **ওই আইডিকেই ডকুমেন্ট ID** বানিয়ে সেভ হয় (status: `pending`)
3. একই সাথে হোয়াটসঅ্যাপে অর্ডার আইডিসহ মেসেজ চলে যায়
4. অ্যাডমিন প্যানেল থেকে স্ট্যাটাস বদলে দিলে কাস্টমার নিজের অর্ডার আইডি দিয়ে "প্রোফাইল" থেকে দেখতে পারবেন (ফোন দিয়ে ট্র্যাকিং নেই, যাতে অন্যের অর্ডার দেখা না যায়)

## পরিবর্তনের ইতিহাস (Changelog)

### বাগ ফিক্স ও নিরাপত্তা আপডেট
- কার্টে (+ বাটন ও "কার্টে যোগ") স্টকের বেশি কোয়ান্টিটি যোগ করা যায় না; চেকআউটের সময়ও স্টক আবার চেক হয়
- চেকআউটে লোকেশন সত্যিই বাধ্যতামূলক (`handleLocationRequiredForCheckout`)
- ইমেজ এডিটর: ক্রপ এখন ঠিক নির্বাচিত অংশটাই কাটে (জুম/সীমা ঠিক, সোনালি বক্স ছবিতে ঢোকে না); রোটেট ৯০° এ ক্যানভাস ও ছবির মাপ ঠিক থাকে
- অর্ডার প্রাইভেসি: `orders` আর পাবলিক লিস্ট নয় (ওপরের বিভাগ দেখুন)

### আগের আপডেট — দারাজ-স্টাইল হোমপেজ ও নতুন ফিল্ড
- ⚡ ফ্ল্যাশ সেল সেকশন (কাউন্টডাউনসহ), 🏷️ ভাউচার স্ট্রিপ, 🕒 সম্প্রতি দেখেছেন সেকশন — এই তিনটাই নতুন, ডেটা না থাকলে অটো-হাইড হয়ে যায়
- ক্যাটাগরি স্ট্রিপ গোল আইকন বাটনে রিডিজাইন
- সার্চ বক্সে ট্রেন্ডিং সার্চ চিপ (খালি অবস্থায় ফোকাস করলে)
- প্রোফাইল ড্রয়ারে আইকন-গ্রিড কুইক-মেনু (উইশলিস্ট/কুপন/ডার্ক মোড/কাস্টমার কেয়ার/শেয়ার/অ্যাপ ইনস্টল/ফেসবুক/WhatsApp)
- প্রোডাক্ট ফর্মে নতুন **ব্র্যান্ড** ফিল্ড ও **ফ্রি ডেলিভারি** চেকবক্স, স্টোরফ্রন্টে সংশ্লিষ্ট ব্যাজ

### এর আগের আপডেটগুলো
- কার্ট ড্রয়ারের প্রোডাক্ট লিস্ট আলাদাভাবে স্ক্রল হওয়া (হেডার/ফর্ম ফিক্সড), "রিভিউ দিন" ট্যাগ প্রোডাক্টের নামের পাশে সরানো, ছবির উপরের ডুপ্লিকেট কুপন-ট্যাগ সরানো, "কার্টে যোগ" এনিমেশন আরও স্পষ্ট করা, হেডারের কাউন্ট ব্যাজ বড়/স্পষ্ট করা, কার্ট ফুটার ফিক্সড-সাইজ করা (প্রোডাক্ট-নির্দিষ্ট কুপন এখন আইটেমের সাথেই দেখায়)
- ফেসবুক ক্যাপশন জেনারেটর ও কুপন জেনারেটর সম্পূর্ণ আলাদা টুলে ভাগ করা
- কুপন কোড সাইটে প্রকাশ্যে দেখানো বন্ধ করা (শুধু লেবেল/ছাড়ের পরিমাণ দেখায়)
- চেকআউটের আগে লোকেশন পারমিশন বাধ্যতামূলক করা
- WhatsApp-এ অর্ডার না যাওয়ার বাগ ঠিক করা (ক্লিকের সাথে সাথে চ্যাট খোলা, বাকি কাজ ব্যাকগ্রাউন্ডে)
- অর্ডার আইডি কপি করার পপআপ (আগে `alert()` দিয়ে দেখাত, মোবাইলে কপি করা যেত না)
- Firestore-এর ডিফল্ট লকড রুলের কারণে হওয়া "Missing or insufficient permissions" এরর ঠিক করা
- একসাথে একাধিক ছবি আপলোড, ছবিসহ WhatsApp শেয়ার, ফ্লোটিং WhatsApp বাটন সিঙ্ক ফিক্স
- কুপন সিস্টেম সম্পূর্ণ নতুন করে বানানো (একাধিক কুপন, ছাড়ের ধরন/সর্বনিম্ন অর্ডার/ব্যবহার সীমা/মেয়াদ, রেস-কন্ডিশন ফিক্স)
- প্রোডাক্ট রিভিউ ও রেটিং ⭐ ফিচার যোগ
- দামের রেঞ্জ ও রেটিং দিয়ে ফিল্টার, সার্চ বিবরণেও খোঁজা
- কুপন প্রয়োগের পর "সর্বমোট" লাইভ দেখানো
- শেয়ার করা প্রোডাক্ট লিংক (`#product-xyz`) সরাসরি খোলা
- প্রোডাক্ট লাইক ফিচার (Firestore `likes` কালেকশন)
- উইশলিস্ট, স্টক স্ট্যাটাস, সর্ট/সাজানো, Open Graph প্রিভিউ কার্ড, প্রোডাক্ট শেয়ার বাটন, রিলেটেড প্রোডাক্ট, ডার্ক মোড
- অ্যাডমিনে লো-স্টক অ্যালার্ট, অর্ডার CSV এক্সপোর্ট
- অফলাইন সাপোর্ট উন্নত করা (sw.js — ছবি cache-first)
- জিওলোকেশন-ভিত্তিক ঠিকানা অটো-ফিল ও ম্যাপ পিন (পরে বাধ্যতামূলক করা হয়েছে, উপরে দেখুন)

### বাদ রাখা হয়েছে (ভবিষ্যতে আলাদাভাবে করা যেতে পারে)
- বাল্ক CSV প্রোডাক্ট আপলোড — বড় স্কোপ, আলাদা টেস্টিং দরকার
- মাল্টি-অ্যাডমিন/রোল — অথেনটিকেশন সিস্টেমে বড় পরিবর্তন লাগবে

### টেস্ট করার সময় খেয়াল রাখুন
- নতুন ফিল্ড (ব্র্যান্ড, ফ্রি ডেলিভারি) `products` কালেকশনে অপশনাল হিসেবে যোগ হয়েছে — পুরনো প্রোডাক্ট ডেটার সাথে কোনো সমস্যা হবে না, শুধু এডিট করে সেভ করলে ব্যাজ দেখা শুরু করবে
- Firestore Rules-এ কোনো নতুন পরিবর্তন লাগেনি এই রাউন্ডে, তবে আগের `likes`/`coupons`/`reviews` কালেকশন যোগ করার সময় একবার Rules Publish করা আবশ্যক ছিল (উপরে দেখুন)
- GitHub-এ আপলোডের নিয়ম আগের মতোই — সব ফাইল রিপ্লেস করে Commit করুন

## ⚡ ফ্ল্যাশ সেল চালানোর নিয়ম (নতুন)
1. অ্যাডমিন → **🛍️ প্রোডাক্ট** → যে প্রোডাক্ট সেলে দিতে চান সেটা এডিট করে "⚡ এই প্রোডাক্ট ফ্ল্যাশ সেলে রাখুন" টিক দিন এবং **ফ্ল্যাশ সেল দাম** লিখে সেভ করুন।
2. অ্যাডমিন → **🏷️ কুপন ও অফার** → **⚡ ফ্ল্যাশ সেল** → চালু টিক দিন, শেষ হওয়ার সময় বাছুন (বা "৬ ঘণ্টা/২৪ ঘণ্টা" বাটন) → **সেভ করুন**।
3. সাইটে হোমপেজের ফ্ল্যাশ সেকশন, প্রোডাক্ট কার্ডের ⚡ ব্যাজ ও প্রোডাক্ট ডিটেইলসে লাইভ টাইমার দেখাবে। সময় শেষ হলে দাম নিজে থেকেই আগের দামে ফিরে যাবে। বন্ধ করতে "⏹ ফ্ল্যাশ সেল বন্ধ করুন"।
